# in car — دليل التشغيل

تطبيق مشاوير ليبي: الراكب يقترح السعر، والسواق يقبل أو يعرض سعره، والراكب يختار العرض اللي يناسبه.

**التقنيات:** Flutter (أندرويد + آيفون) · Supabase (قاعدة البيانات والدخول والتحديث المباشر) · خرائط OpenStreetMap · مسارات OSRM.

---

## الخطوة 1: جهّز Supabase (مجاني)

1. سجّل في https://supabase.com واعمل مشروع جديد. اختار منطقة قريبة مثل Frankfurt.
2. من **SQL Editor** ← **New query**، شغّل الملفات الثلاثة بالترتيب: `supabase/schema.sql` ثم `supabase/wallet.sql` ثم `supabase/services.sql`. ولو عاودت تشغيل واحد منهم، عاود شغّل اللي بعده.
   - قبل `services.sql`، فعّل **pg_cron** من **Database ← Extensions** باش تشتغل تذكيرات الرحلات المحجوزة.
3. من **Project Settings ← API** انسخ الـ **Project URL** والـ **anon public key**.
4. من **Authentication ← Providers ← Phone** فعّل الدخول بالهاتف، واربطه بمزوّد رسائل SMS مثل Twilio أو Vonage أو MessageBird.
   - رسائل التحقق هي الشي الوحيد اللي عليه تكلفة من البداية، والسعر حسب المزوّد.
   - للتجربة بدون تكلفة: في نفس الصفحة، في خانة **Test phone numbers**، تقدر تحط رقم ورمز ثابت، مثل `+218910000000` مع الرمز `123456`.

## الخطوة 2: جهّز مشروع Flutter

لازم يكون Flutter 3.50 أو أحدث مثبّت على جهازك، لأن الكود يستخدم مكتبة material_ui الجديدة: https://docs.flutter.dev/get-started/install

```bash
flutter create --org ly.incar --project-name in_car in_car_app
```

انسخ فوق المشروع الجديد مجلد `lib/` كامل وملف `pubspec.yaml` (استبدلهم)، وبعدها نفّذ:

```bash
cd in_car_app
flutter pub get
```

افتح `lib/config.dart` وحط فيه الـ URL والـ anon key من الخطوة 1.

## الخطوة 3: صلاحيات الموقع والإنترنت

**أندرويد:** في `android/app/src/main/AndroidManifest.xml`، قبل وسم `<application>`، زيد:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
<queries>
  <intent><action android:name="android.intent.action.DIAL"/></intent>
  <intent><action android:name="android.intent.action.VIEW"/><data android:scheme="https"/></intent>
</queries>
```

**آيفون:** في `ios/Runner/Info.plist` زيد:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>نحتاجو موقعك باش نحددو نقطة الانطلاق ونوصلولك أقرب سواق</string>
<key>LSApplicationQueriesSchemes</key>
<array><string>tel</string></array>
```

## الخطوة 4: شغّل التطبيق

```bash
flutter run
```

**طريقة التجربة:** جهّز جوالين، أو جوال ومحاكي، وسجّل دخول برقمين مختلفين: واحد «راكب» والثاني «سائق».
1. السائق يضغط «غير متصل» باش يولّي «متصل».
2. الراكب يختار وجهته، يقترح سعره، ويضغط «اطلب».
3. الطلب يظهر عند السائق مباشرة، فيقبل بنفس السعر أو يعرض سعر ثاني.
4. الراكب يقبل واحد من العروض، والسائق يضغط بالترتيب: «وصلت» ثم «بدء الرحلة» ثم «إنهاء الرحلة».
5. الراكب يقيّم السائق.

## تجربته على الآيفون (نسخة ويب، بدون Mac)

ملف `.github/workflows/web.yml` يبني نسخة الويب، وينشرها مجاناً على GitHub Pages مع كل تعديل.

1. ارفع المشروع على مستودع في GitHub، على الفرع `main`.
2. من المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وزيد سرّين:
   - `SUPABASE_URL`: رابط مشروعك في Supabase.
   - `SUPABASE_KEY`: المفتاح العام (anon / publishable).
3. من **Settings ← Pages**، خلي **Source** على **GitHub Actions**.
4. من تبويب **Actions**، شغّل «Build and publish web app»، أو اعمل أي تعديل على `main`.
5. بعد دقايق يطلعلك رابط مثل `https://اسمك.github.io/in_car/`. افتحه في Safari، واضغط زر المشاركة ثم **«إضافة إلى الشاشة الرئيسية»**.

**ملاحظات على نسخة الويب:**
- Safari بيطلب إذن الموقع أول مرة.
- السائق لازم يخلي الصفحة مفتوحة باش يستقبل الطلبات، لأن نسخة الويب ما توصلهاش إشعارات وهي مقفولة.

## المحفظة والعمولة

- **العمولة:** تتخصم من محفظة السائق تلقائياً لما ينهي الرحلة، مثلاً 7% من الأجرة. الراكب يدفع للسائق نقداً كالعادة.
- **الحد الأدنى للرصيد:** لو رصيد السائق نزل تحته، ما يقدرش يقدّم عروض لين يشحن محفظته. والمنع مطبّق في قاعدة البيانات نفسها، مش في التطبيق بس.
- **فترة بدون عمولة:** تقدر تحددها للإطلاق، مثلاً 90 يوم، باش تجمع سواقين.
- **الشحن:** السائق يدفع نقداً أو بتحويل أو سداد أو موبي كاش، ويبعت طلب شحن من التطبيق برقم العملية. الإدارة تتأكد من الدفع وتضغط «تأكيد الشحن».

**كيف تولّي مدير:** سجّل دخول في التطبيق برقمك، وبعدها شغّل هذا السطر في SQL Editor (حط رقمك بدون +):

```sql
insert into public.admins (user_id) select id from auth.users where phone = '218912345678';
```

بعدها يظهرلك زر **«لوحة الإدارة»** في صفحة حسابي. منها تحدد نسبة العمولة والحد الأدنى للرصيد والفترة المجانية، وتوافق على طلبات الشحن، وتعدّل رصيد أي سائق برقم هاتفه.

## الخدمات

- **مشوار داخل المدينة، توصيل طرد، نقل بضائع:** من الشاشة الرئيسية. لكل خدمة تفاصيلها: حجم الطرد ورقم المستلم، ونوع المركبة وعدد العمّال. ولكل خدمة سعر مقترح خاص بيها، والمعادلات في `lib/data.dart`.
- **السفر بين المدن:** 23 مدينة ليبية، تختار الموعد وعدد المقاعد أو السيارة كاملة.
- **الحجز لوقت معين:** «الآن» أو «حجز لوقت». الرحلات المحجوزة تظهر في «رحلاتي المحجوزة»، والسائق يشوفها فوق قائمة الطلبات. وقبل الموعد بـ 30 دقيقة يوصل تذكير للاثنين.
- **السائق** يختار الخدمات اللي يقدمها ونوع مركبته من «حسابي»، وتوصله بس الطلبات اللي تناسبه.
- **المحادثة:** بين الراكب والسائق أثناء الرحلة، وفيها ردود سريعة جاهزة.
- **أرقام الهواتف مخفية:** الرقم يظهر بس للطرفين أثناء رحلة نشطة.
- **التوثيق:** السائق يرفع 4 وثائق: الرخصة، والبطاقة، وكتيب السيارة، وصورة السيارة. الإدارة تراجعها من «لوحة الإدارة»، ولين ما تتوثق ما يقدرش يقدّم عروض. تقدر تطفّي التوثيق الإجباري للتجربة.
- **الطوارئ والمشاركة:** زر طوارئ يبعت تنبيه فوري للإدارة فيه الموقع، ويتصل برقم الطوارئ اللي تحدده. وزر مشاركة يبعت تفاصيل الرحلة والموقع على واتساب.

## الإشعارات

**الإشعارات الداخلية** تشتغل من غير أي إعداد: كل حدث مهم يظهر كشريط وفي صفحة الجرس. مثلاً طلب جديد، أو عرض جديد، أو قبول، أو وصول السائق، أو رسالة، أو شحن رصيد، أو طوارئ.

**الإشعارات وهو مقفول (Firebase):** إعداد اختياري ومجاني.
1. اعمل مشروع على console.firebase.google.com، وزيد عليه تطبيق Android وتطبيق iOS وتطبيق Web.
2. حط القيم في `--dart-define`، أو في GitHub Secrets لنسخة الويب: `FIREBASE_API_KEY`، `FIREBASE_PROJECT_ID`، `FIREBASE_SENDER_ID`، `FIREBASE_ANDROID_APP_ID`، `FIREBASE_IOS_APP_ID`، `FIREBASE_WEB_APP_ID`، `FIREBASE_VAPID_KEY`.
3. انشر الدالة `supabase/functions/push`، والخطوات مكتوبة في أول الملف نفسه.
4. على الآيفون، نسخة الويب لازم تكون مضافة للشاشة الرئيسية باش توصلها الإشعارات وهي مقفولة (iOS 16.4 أو أحدث).

## ملفات المشروع

| الملف | شن فيه |
|---|---|
| `supabase/schema.sql` | الجداول، صلاحيات الأمان، دوال قبول العرض وتغيير حالة الرحلة والتقييم |
| `supabase/wallet.sql` | المحفظة، العمولة، طلبات الشحن، صلاحيات الإدارة |
| `supabase/services.sql` | الخدمات، الحجز، التوثيق، المحادثة، الطوارئ، الإشعارات |
| `supabase/functions/push/index.ts` | إرسال إشعارات Firebase |
| `lib/data.dart` | المدن الليبية ومعادلات الأسعار |
| `lib/screens/wallet_screens.dart` | محفظة السائق ولوحة الإدارة |
| `lib/config.dart` | مفاتيح Supabase، الخرائط، ومعادلة السعر المقترح |
| `lib/services/api.dart` | كل التعامل مع قاعدة البيانات |
| `lib/services/geo.dart` | الموقع، المسار، البحث عن العناوين، السعر المقترح |
| `lib/screens/auth_screens.dart` | الدخول بالهاتف، رمز التحقق، الملف الشخصي |
| `lib/screens/passenger_screens.dart` | الرئيسية، العروض، الرحلة، التقييم |
| `lib/screens/driver_screens.dart` | الطلبات القريبة، تقديم العروض، إدارة الرحلة |

## قبل الإطلاق الحقيقي (مهم)

- **الخرائط:** بلاطات OpenStreetMap العامة والـ OSRM التجريبي للتطوير بس. قبل الإطلاق بدّلهم من `config.dart` بسيرفرك الخاص أو بمزوّد مدفوع. سيرفر صغير بحوالي 5 إلى 10 دولار في الشهر يكفي OSRM لليبيا كاملة.
- **الترخيص:** راجع الجهات المختصة في ليبيا بخصوص ترخيص نشاط النقل.
- **الاسم:** «in car» قريب من «inDrive»، فتأكد من العلامة التجارية قبل ما تسجل التطبيق في المتاجر.
